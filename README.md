# Sheet Resistance Measurement Analysis

Aggregates the four measurement CSVs of one sample (folder `YYMMDD_<sample>`, files `YYMMDD_<sample>_1..4.csv`)
into mean and standard deviation of sheet resistance, resistivity and conductivity.
